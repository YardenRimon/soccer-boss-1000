# ⚽ כדורגל בוס 100 (Soccer Boss 100)

משחק כדורגל מכשולים מותאם למובייל עם **100 שלבים** ב-10 עולמות שונים (10 שלבים בכל עולם)!

## איך משחקים?
- **קונוסים בזיגזג 🚧**: החלק וכדרר בזיגזג בין הקונוסים בלי לגעת בהם. נגיעה בקונוס, במלכה או במכשול מאפסת את השלב מיד מהתחלה.
- **הבוסית המלכה 👑**: שומרת על הבוס ומחליקה בזיגזג בין הקונוסים מולך כדי לחסום בעיטות ולשגר מכשולים.
- **5 פגיעות בבוס 👹**: הטעה את המלכה, בעט בכדור ופגע בבוס **5 פעמים** (מד חיים של 5 לבבות) כדי לנצח ולעבור לשלב הבא.
- **גשם, ברקים ושעות יום/לילה ⛈️🌙☀️**: כל שלב מתאפיין בשעה אחרת ביממה (זריחה, בוקר, צהריים, שקיעה, דמדומים, ליל סערה), תאורת אצטדיון דינמית, גשם ומכות ברק עם רעם!
- **סגנון וצבע ייחודיים לכל שלב 🎨**: כל אחד מ-100 השלבים מוצג בצבעי מגרש, קונוסים ודוגמת דשא שונים (פסים, משבצות, טבעות מרכז, אלכסונים ומסלולים).
- **כוחות מיוחדים 🔥❄️⚡**: כדור אש (2x נזק), הקפאת המלכה, וטורבו + ירי מהיר.

## שליטה
- **מובייל**: גרור את האצבע על המגרש לתנועה, ולחץ על כפתור **בעיטה! ⚽** (או החלק מהר למעלה / הקש) כדי לבעוט.
- **מחשב**: חיצי המקלדת / `WASD` לתנועה, `Space` לבעיטה.
