# ⚽ כדורגל בוס 1000 (Soccer Boss 1000)

משחק כדורגל מכשולים מותאם למובייל עם **1,000 שלבים** ב-10 עולמות שונים!

## איך משחקים?
- **קונוסים בזיגזג 🚧**: החלק וכדרר בזיגזג בין הקונוסים בלי לגעת בהם. נגיעה בקונוס, במלכה או במכשול מאפסת את השלב מיד מהתחלה.
- **הבוסית המלכה 👑**: שומרת על הבוס ומחליקה בזיגזג בין הקונוסים מולך כדי לחסום בעיטות ולשגר מכשולים.
- **10 פגיעות בבוס 👹**: הטעה את המלכה, בעט בכדור ופגע בבוס **10 פעמים** (מד חיים של 10 לבבות) כדי לנצח ולעבור לשלב הבא.
- **כוחות מיוחדים 🔥❄️⚡**: כדור אש (3x נזק), הקפאת המלכה, וטורבו + ירי מהיר.

## שליטה
- **מובייל**: גרור את האצבע על המגרש לתנועה, ולחץ על כפתור **בעיטה! ⚽** (או החלק מהר למעלה / הקש) כדי לבעוט.
- **מחשב**: חיצי המקלדת / `WASD` לתנועה, `Space` לבעיטה.
