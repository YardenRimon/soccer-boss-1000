# ⚽ כדורגל בוס 100 (Soccer Boss 100)

משחק כדורגל מכשולים מותאם למובייל עם **100 שלבים** ב-10 עולמות שונים (10 שלבים בכל עולם)!

## איך משחקים?
- **קונוסים בזיגזג 🚧**: החלק וכדרר בזיגזג בין הקונוסים בלי לגעת בהם. נגיעה בקונוס, במלכה או במכשול מאפסת את השלב מיד מהתחלה (אלא אם קנית **🛡️ מגן קונוסים** בחנות!).
- **הבוסית המלכה 👑**: שומרת על הבוס ומחליקה בזיגזג בין הקונוסים מולך כדי לחסום בעיטות ולשגר מכשולים.
- **3 רמות קושי 🟢🟡🔴**:
  - **🟢 קל**: פגיעה **1** בבוס לניצחון • מלכה ובוס רגועים • ×1 מטבעות
  - **🟡 רגיל**: **2** פגיעות בבוס לניצחון • קצב מאוזן • ×1.5 מטבעות
  - **🔴 קשה**: **3** פגיעות בבוס לניצחון • מלכה מהירה ואגרסיבית • ×2.5 מטבעות
- **מטבעות וחנות שיפורים 🪙🛒**:
  - אסוף מטבעות זהב על המגרש, פגע בבוס וסיים שלבים כדי להרוויח מטבעות!
  - שדרג בחנות: **👟 נעלי ספרינט** (מהירות כדרור), **⚽ בעיטת תותח** (מהירות כדור וטעינה), **🛡️ מגן קונוסים** (חסינות מפסילה!), **🧲 מגנט מטבעות** ו-**🔥 מתנע כדור אש** (פתיחת שלב עם כדורי אש שעוברים דרך המלכה).
- **גשם, ברקים ושעות יום/לילה ⛈️🌙☀️**: כל שלב מתאפיין בשעה אחרת ביממה, תאורת אצטדיון דינמית, גשם ומכות ברק עם רעם!
- **סגנון וצבע ייחודיים לכל שלב 🎨**: כל אחד מ-100 השלבים מוצג בצבעי מגרש, קונוסים ודוגמת דשא שונים.
