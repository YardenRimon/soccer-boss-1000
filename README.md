# ⚽ כדורגל בוס 1000 (Soccer Boss 1000)

משחק כדורגל מכשולים מותאם למובייל עם **1,000 שלבים** ב-10 עולמות שונים (100 שלבים בכל עולם)!

## איך משחקים?
- **הארי פוטר באמצע (הכי גבוה), רון משמאל והרמיוני מימין (הכי נמוכה) ⚡**: רון והרמיוני **בלתי מנוצחים** — הם שומרים על הארי, חוסמים מכשולים והודפים שומרים, ושלושתם בועטים כדורים ומשליכים **חניתות (`🔱`)**!
- **גדרות אש בלתי עבירות 🔥**: אי אפשר לעבור דרך גדרות האש — חייבים לעקוף אותן!
- **כפתורים ורובים עוקפי מלכה 🔫👻🔥**: **👻 רפאים** ו-**🔥 אש** יורים מהרובים של הארי כדורים שעוברים ישר דרך המלכה.
- **בלבול למלכה ולמלך 🌀😵‍💫**: כפתור **🌀 בלבל** משגר כפילים שמסחררים גם את המלכה וגם את המלך!
- **דרקונים (`🐉 דרקון`) + טילים מאחורי המלך + בורות (`🕳️`)**: הדרקונים חסינים לכדורים, יורים טילים, מצליפים בזנב, ואוכלים את המלכה והמלך כדי להעביר אותך ישר לעולם הבא!
- **שריון זהב נצחי משלב 100+ ✨**: נפתח משלב 100 ומעלה, אינו נעלם לעולם, ומגן על הארי, רון והרמיוני כל הזמן!
- **בוקר גשום עם כוכבים ☀️🌧️⭐**: ללא רוח, עם כוכבים מנצנצים בבוקר וגשם שמפריע למלכה ולמלך.
- **התקדמות קדימה בלבד 💾**: ההתקדמות והמטבעות נשמרים אוטומטית בדפדפן, ולא חוזרים לעולמות אחורה!
