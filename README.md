# ⚽ כדורגל בוס 100 (Soccer Boss 100)

משחק כדורגל מכשולים מותאם למובייל עם **100 שלבים** ב-10 עולמות שונים (10 שלבים בכל עולם)!

## איך משחקים?
- **קונוסים בזיגזג 🚧**: החלק וכדרר בזיגזג בין הקונוסים בלי לגעת בהם (או קנה **✨ שריון זהב** / **🛡️ מגן קונוסים** בחנות!).
- **כפתורים ורובים עוקפי מלכה 🔫👻🔥**:
  - **👻 רובה רפאים**: יורה כדור שעובר ישר דרך המלכה (נטען אוטומטית + תחמושת במגרש ובחנות).
  - **🔥 רובה אש**: יורה כדור אש שעובר דרך המלכה ומוריד 2 חיים למלך!
- **דברים שמבלבלים את המלכה והמלך 🌀😵‍💫**:
  - כפתור **🌀 בלבל** משגר כפילים מבלבלים שמסחררים גם את המלכה וגם את המלך ופותחים נתיב נקי לבעיטה!
- **הארי פוטר באמצע עם רון והרמיוני בצדדים ⚡**: הארי פוטר (משקפיים, צלקת ברק וגלימה / שריון זהב) יורה את הכדורים, ורון והרמיוני נעים באגפי המגרש, חוסמים מכשולים של המלכה ויורים כדורי סיוע למלך!
- **בורות + טילים מאחורי המלך 🕳️🚀**:
  - בורות באזור המלך לוכדים אותו לרגע במקום.
  - טילים מרחפים מאחורי המלך ומונעים ממנו לברוח אחורה — ואם טיל פוגע במלך, עוברים ישר לעולם הבא!
- **גדלים בכל פגיעה 💪✨**: כל פגיעה במלך מגדילה את השחקן שלך!
- **שריון זהב וחנות שיפורים ✨🛒**: אסוף מטבעות על הדשא ונצח שלבים כדי לקנות **✨ שריון זהב**, רובים, מהירות ומגנים.
- **3 רמות קושי 🟢🟡🔴**, גשם וברקים ⛈️, ושעות יום/לילה + סגנון וצבע ייחודי לכל שלב 🎨.
